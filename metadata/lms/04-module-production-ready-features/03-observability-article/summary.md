Observability closes the loop on running a Spring AI application in earnest. It is built on **Micrometer and Spring Boot Actuator**, so your AI operations produce **metrics** and **distributed traces** through the same stack as the rest of your application, with no new tooling. Every layer you have built is instrumented, from the ChatClient and the advisors to the ChatModel, the tools, and the vector store, so a trace mirrors the request while a dashboard tracks the system. **Token usage metrics** make spend visible and chartable, while **content logging for prompts and completions stays opt-in** to protect sensitive data. In the next section you wire this up, enable Actuator, watch the spans of a real request to your support assistant, and read its token usage and latency for yourself.
