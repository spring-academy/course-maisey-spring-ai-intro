You have now seen how Spring AI turns the tool calling pattern into ordinary Java. You write methods, describe them well with `@Tool` and `@ToolParam`, hand them to the `ChatClient`, and let the `ToolCallingAdvisor` run the request, execute, and respond loop for you. You use `ToolContext` to keep sensitive data out of reach of the model, and you can combine tools with RAG and everything else on the same client. In the next section you extend the support assistant with tools, so it moves from explaining problems to resolving them.
