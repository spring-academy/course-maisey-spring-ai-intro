You built a support assistant with Spring AI, starting from an empty project and ending with a chat endpoint that returns structured data and runs shared behavior around every call. That shared behavior comes from the advisor pattern, an interceptor that wraps each `ChatClient` call before and after the model, without touching your prompting code. You used it to log every request and response, and to add conversation memory with the `MessageChatMemoryAdvisor`, which replays earlier interactions so the model can follow up on what was said before.
