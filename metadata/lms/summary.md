## Overview
A short course that intorduces you to Spring AI, a framework that enables you to integrate GenAI capabilites into your enterprise applications.

## Prequisites
* Familiarity with Spring Boot
* Basic understanding of REST APIs

## Learning Outcomes:
* Build AI-powered Spring Boot applications using the Spring AI `ChatClient` API
* Apply prompt engineering techniques including system prompts and few-shot examples
* Map AI responses to typed Java objects using structured output
* Implement Retrieval-Augmented Generation (RAG) with embeddings and vector stores
* Extend AI capabilities with custom tools via Tool Calling and the Model Context Protocol (MCP)
* Maintain conversation history across turns using Spring AI Advisors
* Monitor AI application performance with Micrometer observability integration
* Validate AI output quality using the Spring AI Evaluator testing framework
